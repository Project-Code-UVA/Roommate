**src/services/message-service.ts:**
- Import supabase from @/lib/supabase, types from @/types/chat
- Use same `const rpc = supabase.rpc.bind(supabase) as any` pattern from match-service.ts
- `sendMessage(params: SendMessageParams, senderId: string)`: call rpc('send_message', { p_thread_id, p_sender_id: senderId, p_body, p_media_url, p_reply_to_id, p_message_id: params.message_id }). Parse jsonb response for success/error.
- `addReaction(messageId: string, userId: string, emoji: string)`: insert into message_reactions, return { data: reaction, error }
- `removeReaction(reactionId: string)`: delete from message_reactions by id
- `updateDeliveryStatus(messageId: string)`: update messages set delivered_at = new Date().toISOString() where id = messageId and delivered_at is null
- `deleteMessageForMe(messageId: string, userId: string)`: For MVP, delete the message row for the user. Use a deleted_by_user_ids approach or simply filter client-side. Simplest: add to a local AsyncStorage blacklist of hidden message IDs (no schema change needed). Return { success, error }.

**src/services/thread-service.ts:**
- `getThreads(userId: string)`: Query threads where user_a_id or user_b_id = userId AND status = 'active'. Join profiles for the other user (determine other_user based on which ID != userId). For each thread, get the latest message and count of messages where delivered_at is null and sender_id != userId. Order by last message created_at desc, fallback to thread created_at.
- `getThread(threadId: string)`: Get single thread by id with other_user profile join.
- `markThreadDelivered(threadId: string, userId: string)`: Update all messages in thread where sender_id != userId AND delivered_at IS NULL, set delivered_at = now().

**src/services/gif-service.ts:**
- Use EXPO_PUBLIC_GIPHY_API_KEY env var
- `searchGifs(query, offset=0, limit=20)`: fetch GIPHY /search endpoint, map response to GifResult[], use rating=pg-13
- `trendingGifs(offset=0, limit=20)`: fetch GIPHY /trending endpoint, same mapping
- Both return { data: readonly GifResult[] | null, error: string | null }

**src/hooks/use-chat-messages.ts:**
- useState for messages (Message[]), isLoading, hasMore
- useEffect on mount: fetch initial page (25 messages, ordered by created_at desc) via supabase.from('messages').select('*, reply_to:messages!reply_to_id(id,body,sender_id)').eq('thread_id', threadId).order('created_at', { ascending: false }).limit(25)
- useEffect for Realtime: subscribe to channel `chat:${threadId}` with postgres_changes INSERT and UPDATE on messages filtered by thread_id. On INSERT from other user: prepend to messages state AND call markThreadDelivered. On UPDATE: merge delivered_at/read_at into existing message.
- loadMore: fetch next page using cursor (created_at < oldest message's created_at), append to end of messages array. Set hasMore=false when returned count < page size.
- Cleanup: remove channel on unmount
- Return { messages, isLoading, hasMore, loadMore }

**src/hooks/use-message-actions.ts:**

- sendText(body: string, replyToId?: string): generate UUID via crypto.randomUUID(), create optimistic Message with _status='sending', dispatch to messages state (need a setter callback or context), call sendMessage service. On success update _status to 'sent', on error update to 'failed'.
- sendMedia(mediaUrl: string, caption?: string, replyToId?: string): same pattern with media_url
- sendReaction(messageId: string, emoji: string): call addReaction service, optimistically add reaction to local state
- removeReaction(reactionId: string): call removeReaction service, optimistically remove
- sendReply(body: string, replyToId: string): delegates to sendText with replyToId
- copyText(text: string): use expo-clipboard to copy
- deleteForMe(messageId: string): call deleteMessageForMe service, remove from local state
- Return all action functions
