**app/(tabs)/messages.tsx** - Thread list (conversations overview):
- Use useAuth hook to get current user
- Fetch threads on mount via getThreads(userId)
- FlatList of threads, each item shows:
  - Avatar (other_user.avatar_url or fallback icon), circular 48px
  - Display name (other_user.display_name), bold
  - Last message preview (truncated at 40 chars), gray text
  - Timestamp of last message (relative: "2m", "1h", "Yesterday", etc.)
  - Unread count badge (small purple circle with count, only if > 0)
- Tapping a thread: router.push(`/chat/${thread.id}?otherUserId=${thread.other_user.id}&otherName=${thread.other_user.display_name}&otherAvatar=${thread.other_user.avatar_url}`)
- Empty state: "No conversations yet" with illustration/icon, text "Match with someone to start chatting"
- Pull-to-refresh: refetch threads
- Header title: "Messages"

**app/chat/[threadId].tsx** - Individual chat screen (dynamic route):
- Read threadId from useLocalSearchParams()
- Read otherUserId, otherName, otherAvatar from search params
- Use useAuth for currentUserId
- Use useChatMessages(threadId, currentUserId) for messages + realtime
- Use useMessageActions(threadId, currentUserId) for all actions
- State management: replyingTo (Message | null), showGifPanel (boolean), showLongPress (boolean), longPressMessage (Message | null), photoUri (string | null), showPhotoPreview (boolean)
- Layout (top to bottom):
  1. ChatHeader: otherUser data, onBack=router.back, onPressProfile opens profile bottom sheet (reuse Phase 4 pattern), onPressBlock calls blockFromChat then router.back, onPressReport opens report bottom sheet
  2. If messages empty and no icebreaker dismissed: IcebreakerCard (dismissed state in AsyncStorage key `icebreaker_dismissed_${threadId}`)
  3. MessageList: pass messages, currentUserId, onLongPress (show long-press menu), onImagePress (open full-screen viewer -- Pressable with Modal for now), onReactionPress, onReplyPress (scroll to original), onEndReached
  4. If photoUri: PhotoPreview with onSend (upload photo via uploadChatPhoto from photo upload util based on Phase 2 pattern, then sendMedia), onCancel
  5. If showGifPanel: GifSearchPanel with onSelectGif (sendMedia with gif URL), matching keyboard height
  6. MessageComposer: onSend=sendText, onCameraPress (open expo-image-picker action sheet per user decision), onGifPress (toggle GIF panel, dismiss keyboard), replyTo=replyingTo, onDismissReply
- Long-press flow: set longPressMessage + showLongPress=true, LongPressMenu overlays with callbacks:
  - onReact(emoji): sendReaction(longPressMessage.id, emoji), close menu
  - onReply: set replyingTo=longPressMessage, close menu, focus composer
  - onCopy: copyText(longPressMessage.body), close menu
  - onDelete: deleteForMe(longPressMessage.id), close menu
  - onReport: close menu, open report bottom sheet
- Swipe-to-reply: on MessageBubble, detect swipe-right gesture (Gesture.Pan with activeOffsetX threshold), when triggered set replyingTo=that message and focus composer. Use same gesture pattern from Phase 4 (Gesture.Race to avoid conflict with scroll).
- Report bottom sheet: @gorhom/bottom-sheet with list of 8 ReportCategory options, tapping one calls submitReport and closes sheet
- Block confirmation: Alert.alert with "Block [name]?" confirmation before calling blockFromChat
- KeyboardAvoidingView wrapping the whole screen with behavior="padding" on iOS
- Install expo-clipboard: `npx expo install expo-clipboard`
