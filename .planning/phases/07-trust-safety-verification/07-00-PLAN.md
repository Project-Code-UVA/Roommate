**00048_block_user_rpc.sql** -- Create a standalone `block_user(p_blocker_id uuid, p_blocked_id uuid)` RPC that:
- Returns `jsonb_build_object('error', 'cannot_block_self')` if blocker == blocked
- Inserts into `blocks` table with `ON CONFLICT DO NOTHING` (idempotent)
- Inserts permanent dismissal into `dismissals` with `view_count = 3, last_dismissed_at = now()` using `ON CONFLICT (dismisser_id, dismissed_id) DO UPDATE SET view_count = 3, last_dismissed_at = now()`
- Updates `matches` SET `unmatched_at = now(), unmatched_by = p_blocker_id` WHERE `user_a_id = LEAST(p_blocker_id, p_blocked_id) AND user_b_id = GREATEST(p_blocker_id, p_blocked_id) AND unmatched_at IS NULL` (only if match exists)
- Updates `threads` SET `status = 'blocked'` WHERE `user_a_id = LEAST(...) AND user_b_id = GREATEST(...)` (only if thread exists)
- Deletes likes in both directions: `DELETE FROM likes WHERE (liker_id = p_blocker_id AND liked_id = p_blocked_id) OR (liker_id = p_blocked_id AND liked_id = p_blocker_id)`
- Returns `jsonb_build_object('success', true)`
- Use `SECURITY DEFINER` and `SET search_path = public`

**00049_apply_enforcement.sql** -- Create `apply_enforcement_action(p_admin_id uuid, p_user_id uuid, p_action enforcement_action_type)` RPC that:
- Inserts into `enforcement_actions` table with `user_id = p_user_id, action = p_action, start_at = now()`
- Sets `end_at` based on action type:
  - `warning`: `end_at = NULL` (one-time modal, no duration)
  - `dm_ban_48h`: `end_at = now() + interval '48 hours'`
  - `suspended_7d`: `end_at = now() + interval '7 days'`
  - `permanent_ban`: `end_at = NULL`
- Updates `users` SET `enforcement_state = p_action::text::enforcement_state` WHERE `id = p_user_id`
- Returns `jsonb_build_object('success', true, 'enforcement_action_id', v_action_id)`
- Use `SECURITY DEFINER` and `SET search_path = public`

**00050_selfie_storage.sql** -- Create selfie storage bucket and RLS policies:
- `INSERT INTO storage.buckets (id, name, public) VALUES ('selfies', 'selfies', true)` for public read of verified badges
- Storage policy for authenticated user upload: `CREATE POLICY "Users can upload own selfie" ON storage.objects FOR INSERT WITH CHECK (bucket_id = 'selfies' AND (storage.foldername(name))[1] = auth.uid()::text)`
- Storage policy for upsert/update: `CREATE POLICY "Users can update own selfie" ON storage.objects FOR UPDATE USING (bucket_id = 'selfies' AND (storage.foldername(name))[1] = auth.uid()::text)`
- Storage policy for public read: `CREATE POLICY "Public read selfies" ON storage.objects FOR SELECT USING (bucket_id = 'selfies')`
- Also create a simple RPC `set_selfie_verified(p_user_id uuid)` that updates `users SET selfie_verified = true WHERE id = p_user_id` and returns `jsonb_build_object('success', true)`. Use `SECURITY DEFINER`.
