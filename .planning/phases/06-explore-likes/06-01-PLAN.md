    - getProfileDetail(userId, targetId) fetches full DiscoveryProfile for a single user (reuse get_discovery_stack with filter or create simple query)
    - Returns empty array on error, never throws

    use-explore-feed:
    - Loads initial page (24 profiles) on mount
    - loadMore appends next page with same seed (offset increments)
    - refresh generates new random seed and reloads from offset 0
    - selectProfile sets selectedProfile state (for full profile view)
    - likeSelected calls likeProfile, removes from feed optimistically, returns LikeResult for match detection
    - dismissSelected calls dismissProfile, removes from feed optimistically
    - clearSelected resets selectedProfile to null
    - isLoading, isRefreshing, hasMore state flags
  </behavior>
  <action>
1. Create `src/services/explore-service.ts`:
   - Import supabase client and ExploreProfile type.
   - `getExploreFeed(userId: string, limit = 24, offset = 0, seed = 0)` — calls `supabase.rpc('get_explore_feed', { p_user_id, p_limit, p_offset, p_seed })`. Returns `{ data: readonly ExploreProfile[], error: string | null }`. On error, return `{ data: [], error: message }`.
   - `getProfileDetail(userId: string, targetId: string)` — direct query: join profiles + users + photos for a single user. Returns `{ data: DiscoveryProfile | null, error }`. This avoids calling the full discovery stack RPC for one profile.
   - Never throw. Always return structured result.

2. Create `src/hooks/use-explore-feed.ts`:
   - State: `profiles` (ExploreProfile[]), `selectedProfile` (DiscoveryProfile | null), `selectedExploreProfile` (ExploreProfile | null), `isLoading`, `isRefreshing`, `hasMore`, `seed` (number, random on mount).
   - `loadInitial()`: called on mount via useEffect. Sets loading, calls getExploreFeed with seed, sets profiles.
   - `loadMore()`: if !isLoading && hasMore, increment offset by limit, append results. If results < limit, set hasMore=false.
   - `refresh()`: generate new seed via `Math.floor(Math.random() * 2147483647)`, reset offset to 0, reload.
   - `selectProfile(profile: ExploreProfile)`: set selectedExploreProfile, call getProfileDetail to fetch full data, set selectedProfile.
   - `likeSelected()`: call likeProfile(userId, selectedProfile.user_id). Remove from profiles array (immutable filter). Clear selected. Return the LikeResult for match detection.
   - `dismissSelected()`: call dismissProfile(userId, selectedProfile.user_id). Remove from profiles. Clear selected.
   - `clearSelected()`: set both selected states to null.
   - All state updates must be immutable (spread/filter, never mutate).

Uncomment imports in test stubs and implement tests alongside.
