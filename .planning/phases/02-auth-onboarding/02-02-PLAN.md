1. **OTP Input Component** (`src/components/onboarding/otp-input.tsx`):
   - Props: `onComplete: (code: string) => void`, `length?: number` (default 6)
   - Render `length` individual TextInput boxes in a row, each: w-12 h-14 border-2 border-gray-300 rounded-xl text-center text-2xl font-bold, focused border becomes purple-600
   - Auto-advance: when user types a digit, move focus to next input
   - Paste support: if text.length === length, split into digits and fill all boxes, call onComplete
   - Backspace: on empty input backspace, move focus to previous input and clear it
   - Auto-focus first input on mount
   - Use `useRef<TextInput[]>([])` array for refs
   - `keyboardType="number-pad"`, `maxLength={1}` per input, `textContentType="oneTimeCode"` for iOS autofill

2. **Phone Screen** (`app/(auth)/phone.tsx`):
   - Uses `StepContainer` with title "What's your phone number?" and subtitle "We'll send you a verification code"
   - Phone input: "+1" country code label (fixed, non-editable) + TextInput for 10-digit number
   - Format display as user types: (xxx) xxx-xxxx
   - "Send Code" button (purple-600, full width), disabled until 10 digits entered
   - On press:
     - Show loading state on button
     - Call `sendOtp(phoneNumber)` from auth-service (strips formatting, sends raw digits)
     - On success: save phone to onboarding progress, navigate to `/(auth)/verify-otp` passing phone as param
     - On error: show error text below input (red-500)
   - Back button navigates to birthday

3. **OTP Verification Screen** (`app/(auth)/verify-otp.tsx`):
   - Uses `StepContainer` with title "Enter verification code" and subtitle showing "Code sent to +1 (xxx) xxx-xxxx" using the phone from route params
   - Renders `OtpInput` component
   - On complete (all 6 digits entered):
     - Show loading spinner
     - Call `verifyOtp(phone, code)` from auth-service
     - On success (session returned):
       - Retrieve birthdate from onboarding progress
       - Call `createUserRecord(session.user.id, birthdate, phone)` to create `users` row
       - Save progress, navigate to `/(auth)/name`
     - On error: show error text, clear OTP input, refocus first box
   - Resend section below OTP input:
     - "Didn't get the code?" text
     - "Resend" button with 60-second countdown timer (shows "Resend in 45s" while counting)
     - On resend: call `sendOtp(phone)` again, restart timer
   - Back button navigates to phone screen
  </action>
