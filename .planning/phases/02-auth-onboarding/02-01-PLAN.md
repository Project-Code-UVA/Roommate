  <name>Task 3: Service layer for auth, photos, schools, and profiles</name>
  <files>src/services/auth-service.ts, src/services/photo-service.ts, src/services/school-service.ts, src/services/profile-service.ts</files>
  <action>
1. **auth-service.ts**:
   - `validateAge(birthdate: Date): boolean` — returns true if 18+ (client-side pre-check; server enforces via trigger)
   - `sendOtp(phone: string): Promise<{ error: string | null }>` — calls `supabase.auth.signInWithOtp({ phone: '+1' + phone })`, returns error message or null
   - `verifyOtp(phone: string, token: string): Promise<{ session: Session | null; error: string | null }>` — calls `supabase.auth.verifyOtp({ phone, token, type: 'sms' })`
   - `createUserRecord(userId: string, birthdate: string, phone: string): Promise<{ error: string | null }>` — inserts into `users` table
   - `markOnboardingComplete(userId: string): Promise<{ error: string | null }>` — updates `users.onboarding_completed = true`

2. **photo-service.ts**:
   - `pickImage(source: 'camera' | 'gallery'): Promise<ImagePickerResult>` — launches picker with `allowsEditing: true`, `aspect: [1, 1]`, `quality: 0.8`
   - `uploadPhoto(userId: string, uri: string, orderIndex: number): Promise<{ url: string; error: string | null }>` — reads base64 via FileSystem, decodes via `decode()` from `base64-arraybuffer`, uploads to `photos` bucket at `{userId}/{timestamp}.jpg`, inserts row into `photos` table with `order_index`
   - `deletePhoto(userId: string, photoId: string, filePath: string): Promise<{ error: string | null }>` — removes from storage and deletes `photos` row
   - `reorderPhotos(userId: string, photoIds: string[]): Promise<{ error: string | null }>` — updates `order_index` for each photo

3. **school-service.ts**:
   - `searchSchools(query: string): Promise<School[]>` — queries `schools` table with `ilike` filter on `name`, returns matching schools
   - `getUserSchools(userId: string): Promise<School[]>` — queries `user_schools` join `schools`
   - `addUserSchool(userId: string, schoolId: string): Promise<{ error: string | null }>` — inserts into `user_schools`
   - `removeUserSchool(userId: string, schoolId: string): Promise<{ error: string | null }>` — deletes from `user_schools`

4. **profile-service.ts**:
   - `updateProfile(userId: string, fields: Partial<ProfileUpdate>): Promise<{ error: string | null }>` — upserts into `profiles` table
   - `getProfile(userId: string): Promise<Profile | null>` — selects from `profiles`
   - Type `ProfileUpdate = { display_name, bio, year, gender, show_gender, hometown, nitty_gritty }`
