Build the photo upload and bio screens -- the final two onboarding steps -- and wire the completion flow that marks the user as fully onboarded.

1. **Photo Grid Component** (`src/components/onboarding/photo-grid.tsx`):
   - Props: `photos: PhotoSlot[]`, `onAdd: (index: number) => void`, `onRemove: (index: number) => void`, `onReorder: (fromIndex: number, toIndex: number) => void`
   - Type `PhotoSlot = { id: string; uri: string; uploaded: boolean } | null`
   - Layout: 3-column grid using flexWrap
   - Initially shows 3 slots (the required minimum). After all 3 are filled, show a "+" button that adds more slots (up to 9 total).
   - Empty slots: dashed border (border-2 border-dashed border-gray-300 rounded-xl), "+" icon centered, onPress calls `onAdd(index)`
   - Filled slots: show image (rounded-xl, aspect-square), small "x" button overlay (top-right, bg-black/50 rounded-full) for removal
   - First slot has a small "Profile" label badge (bg-purple-600 text-white text-xs rounded-full px-2 py-0.5) at bottom center
   - Long-press drag reorder using `react-native-gesture-handler` GestureDetector + `react-native-reanimated` for smooth animation:
     - On long press: scale up slightly (1.05), add shadow
     - On drag: translate position, swap with target slot
     - On release: animate back to grid position, call `onReorder`
   - Haptic feedback on long-press start (expo-haptics `impactAsync`)

2. **Photos Screen** (`app/(auth)/photos.tsx`):
   - Uses `StepContainer` with title "Add your photos" and subtitle "You need at least 3 photos. First photo is your profile photo."
   - State: `photos: PhotoSlot[]` (initialized as `[null, null, null]`)
   - On add (slot tapped):
     - Show ActionSheet/Alert with options: "Take Photo", "Choose from Library", "Cancel"
     - Call `pickImage('camera')` or `pickImage('gallery')` from photo-service
     - If image returned: show loading overlay on slot, call `uploadPhoto(userId, uri, slotIndex)`, on success update slot with `{ id, uri, uploaded: true }`
     - On error: show toast/alert with error message
   - On remove: call `deletePhoto` from photo-service, set slot back to null, compact remaining photos (no gaps)
   - On reorder: call `reorderPhotos` from photo-service with new order
   - "Continue" button (purple-600, full width), disabled if fewer than 3 photos uploaded
   - Counter text below grid: "{count}/3 required photos" (or "{count} photos" if >= 3)
   - Back button navigates to school

   - On press:
     1. Show loading state on button
     2. Call `updateProfile(session.user.id, { bio: bio.trim() })` from profile-service
     3. Call `markOnboardingComplete(session.user.id)` from auth-service — sets `onboarding_completed = true` in users table
     4. Call `refreshOnboardingStatus()` from auth context — this re-queries the users table and updates `onboardingComplete` state
     5. Clear onboarding progress from AsyncStorage via `clearProgress()`
     6. The auth context state change (`onboardingComplete` becoming true) triggers the `(tabs)/_layout.tsx` to stop redirecting, and the user sees the main app
   - On error at any step: show error alert, do NOT mark complete if profile save failed
   - Back button navigates to photos
