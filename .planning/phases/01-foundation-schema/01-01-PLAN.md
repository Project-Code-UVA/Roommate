<task type="auto">
  <name>Task 1: Create Expo project with NativeWind and Supabase client</name>
  <files>
    app/_layout.tsx, global.css, tailwind.config.js, metro.config.js, babel.config.js,
    nativewind-env.d.ts, tsconfig.json, src/lib/supabase.ts, src/lib/constants.ts,
    .env.example, .gitignore, app.json
  </files>
  <action>
    1. Create Expo project using SDK 52 template:
       ```bash
       npx create-expo-app@latest roommate --template default@sdk-52
       ```
       Then move contents to the repo root (or create in-place if repo root is empty).

    2. Install dependencies:
       ```bash
       npx expo install @supabase/supabase-js @react-native-async-storage/async-storage
       npm install nativewind react-native-reanimated react-native-safe-area-context
       npm install --save-dev tailwindcss@^3.4.17 supabase
       ```

    3. Configure NativeWind (CRITICAL — exact order matters, see RESEARCH.md Pitfall 1):
       - `babel.config.js`: Add `nativewind/babel` preset with `jsxImportSource: "nativewind"`
       - `metro.config.js`: Wrap with `withNativeWind` pointing to `./global.css`
       - `tailwind.config.js`: Add `nativewind/preset` to presets, content paths for `./app/**` and `./src/**`, extend theme with purple/violet primary palette (primary-50 through primary-900, primary-600 = #7C3AED as main brand color)
       - `global.css`: Tailwind directives (`@tailwind base; @tailwind components; @tailwind utilities;`)
       - `nativewind-env.d.ts`: `/// <reference types="nativewind/types" />` — MUST NOT be named `nativewind.d.ts` (conflicts with module)
       - `app/_layout.tsx`: Import `../global.css` at the top

    4. Configure Supabase client singleton at `src/lib/supabase.ts`:
       - Import AsyncStorage for auth persistence
       - Import Database type from `@/types/database.types` (will be generated in Plan 03)
       - Use `process.env.EXPO_PUBLIC_SUPABASE_URL` and `process.env.EXPO_PUBLIC_SUPABASE_ANON_KEY`
       - Set `detectSessionInUrl: false` (critical for React Native — see RESEARCH.md Pitfall 5)
       - Set `autoRefreshToken: true`, `persistSession: true`
       - For now, use a placeholder `Database` type (`export type Database = Record<string, never>`) in a temporary `src/types/database.types.ts` that will be overwritten by generated types in Plan 03

    5. Create `src/lib/constants.ts` with app-wide constants:
       - App name, version
       - Tab names array
       - Color palette constants matching tailwind.config.js

    6. Create `.env.example` with placeholder values:
       ```
       EXPO_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
       EXPO_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
       ```

    7. Update `.gitignore` to include `.env`, `.env.local`, and any Expo-specific ignores.

    8. Configure `tsconfig.json` path aliases: `@/*` maps to `./src/*`
  </action>
  <verify>
    <automated>npx expo doctor && npx tsc --noEmit</automated>
  </verify>
  <done>
    Expo project created with all NativeWind config files, Supabase client singleton, TypeScript path aliases, and environment variable template. TypeScript compiles without errors.
  </done>
